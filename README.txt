This tour was built with Panotour Lite.

How to publish: upload the entire contents of this archive to any hosting (GitHub Pages, Netlify, a regular website) and open index.html.
You cannot open index.html with a double click from disk: the browser does not let WebGL read local images. For that, use the "Single HTML file" export.
The tour.json file lets you reopen this archive in the editor later and keep working.
